# Перенос проекта из AutoCAD в Revit: что делаете вы

Это часть для человека. Построение элементов выполняет Claude через сервер Horizun по навыку
`dwg-to-revit`; от вас нужны подготовленные чертежи, проект Revit и решения, которые нельзя
принять за вас.

Порядок составлен по документации Horizun 4.0.0 и в работающем Revit ещё не проверялся. Начните
с одного этажа одного раздела.

## Чего ожидать

- Переносится геометрия с планов: оси, стены, перекрытия, колонны, балки, фундаменты, проёмы,
  двери, окна, помещения, воздуховоды, трубы, оборудование.
- Не переносятся высоты (их задаёте вы), тексты (марки, номера осей и помещений задаются в
  правилах), узлы, разрезы и спецификации.
- Арматура по планам не строится. Её можно получить отдельно — из ведомостей армирования.
- Инженерные сети после построения нужно отдельно соединить; до этого они — набор отрезков.

## 1. Подготовьте чертежи в AutoCAD

Сделайте копии файлов и работайте с копиями.

1. **Один файл — один план одного этажа.** Разнесите этажи и разделы по отдельным файлам.
   Разрезы, узлы, листы оформления, рамки и штампы уберите.
2. **Пространство модели, масштаб 1:1, единицы — миллиметры.** Проверьте командой `UNITS` и
   измерьте известный размер.
3. **Общая точка.** Во всех файлах одна и та же точка здания (например, пересечение осей А и 1)
   должна иметь одинаковые координаты. Удобнее всего перенести её в 0,0.
4. **Слои по смыслу.** Главное условие успеха. На отдельных слоях должны лежать:
   - оси;
   - наружные стены, внутренние стены, перегородки — раздельно, если это разные типы;
   - колонны, балки, плиты, фундаменты;
   - двери, окна;
   - воздуховоды и трубы — по системам, а лучше и по сечениям;
   - оборудование.

   Штриховки, размеры, тексты и выноски держите на своих слоях: их просто не включат в правила.
5. **Разбейте специальные объекты.** Объекты СПДС, Model Studio и другие прокси-объекты
   превратите в обычные линии и полилинии (`EXPLODE`, для прокси — экспорт в примитивы).
   Иначе Revit может их не загрузить.
6. **Внешние ссылки.** Либо внедрите их (`XREF` → «Внедрить»), либо переносите каждый файл
   ссылки как отдельный чертёж.
7. **Контуры замкните.** Плиты, помещения, отверстия и фундаменты должны быть замкнутыми
   полилиниями.
8. **Почистите файл:** `PURGE`, `AUDIT`, затем сохраните в формате DWG 2018.

## 2. Подготовьте проект Revit

1. Создайте новый проект по вашему шаблону. Для первой пробы — один файл; для работы лучше
   отдельные файлы для АР, конструкций и ОВ, связанные между собой.
2. Создайте уровни с точными отметками. Запишите их названия.
3. Загрузите семейства и создайте типы, которые понадобятся: стены нужных толщин, перекрытия,
   колонны, балки, фундаменты, двери и окна, воздуховоды и трубы с системами.
4. Сохраните проект и работайте в нём, а не в рабочем файле.

## 3. Что сообщить Claude

- папку с подготовленными чертежами и какой файл к какому этажу и разделу относится;
- отметки и высоты этажей;
- какие типы стен, перекрытий и семейства использовать;
- имена осей по порядку;
- системы ОВ и их обозначения на слоях.

Пример запроса: «Перенеси план первого этажа АР из `D:\Проект\АР_этаж1.dwg`. Отметка 0.000,
высота этажа 3300. Наружные стены — "Кирпич 510", перегородки — "Перегородка 120"».

## 4. Ваши решения по ходу работы

Claude остановится и спросит вас в этих местах:

| Момент | Что решаете |
| --- | --- |
| После чтения слоёв | Что означает каждый слой и какой тип ему соответствует |
| Стены с проёмами | Какой разрыв считать проёмом, а не концом стены |
| Перед построением | Согласны ли с планом: сколько и чего будет создано, что отложено |
| После проверки | Что делать с расхождениями между моделью и чертежом |
| Новая версия чертежа | Какие перемещения, разделения и удаления принять |
| Армирование | Проверка требований к армированию перед построением |

Каждое построение — обычная операция Revit, её можно отменить.

## 5. Рекомендуемая последовательность

1. Уровни и оси.
2. КЖ: колонны, несущие стены, плиты, фундаменты.
3. АР: стены и перегородки, затем перекрытия, затем двери, окна, отверстия, помещения.
4. КМ: колонны, балки, связи.
5. ОВ: воздуховоды и трубы, оборудование, затем соединение в сети.
6. Армирование — отдельно, после проверки конструкций.

После каждого шага смотрите результат в Revit до перехода к следующему.

## 6. Что останется сделать вручную

- узлы и соединения металлоконструкций;
- оформление: виды, листы, размеры, марки, спецификации (здесь поможет второй сервер,
  BIMwright; он включается кнопкой **Надстройки → RvtMcp → MCP: ON**);
- всё, чего не было на планах: отметки по высоте, уклоны, отделка.
