# Установка MCP-серверов Revit

Задача: поставить на рабочую станцию Windows два сервера — **Horizun** и **BIMwright rvt-mcp** — и
подключить их к Claude Code и Claude Desktop. Всё делает один скрипт
`scripts/Install-RevitMcp.ps1`; твоя работа — подготовить запуск, показать человеку, что будет
сделано, запустить и проверить результат.

Скрипт проверен тестами и пробным прогоном без Windows; на настоящей станции с Revit он ещё не
запускался. Поэтому первый запуск всегда через `-DryRun`, и о любом расхождении сообщай человеку
дословно.

## Чего не делать

- Не ставь и не активируй Revit, не трогай лицензии Autodesk.
- Не скачивай установщики из интернета: только файлы из папки набора. Если файла нет — остановись
  и скажи, какого.
- Не продолжай при несовпадении SHA-256. Ключ `-SkipHashCheck` применяй только если человек
  прямо сказал, что доверяет файлу; несовпадающий хэш он всё равно не пропустит.
- Не включай выполнение произвольного кода (`-EnableSendCode`, кнопка Python в Horizun), пока
  человек сам об этом не попросит.
- Не правь настройки клиентов вручную, если это делает скрипт, и не запускай установщики
  серверов без ключей, указанных ниже: по умолчанию они сами прописываются во все найденные
  клиенты.
- Не закрывай Revit сам. Если он запущен — попроси человека сохранить работу и закрыть.

## Шаг 1. Выясни исходные данные

1. Где лежит офлайн-набор (папка с `horizun-mcp-*-setup.exe` и `RvtMcp.Setup-*-win-x64.zip`).
   Если человек не назвал папку — спроси.
2. Какие клиенты нужны: Claude Code, Claude Desktop или оба. По умолчанию оба; отсутствующий
   клиент скрипт пропустит сам.
3. Нужны ли оба сервера. Для переноса чертежей из AutoCAD достаточно Horizun
   (`-Servers Horizun`); BIMwright нужен для прямого создания элементов.

## Шаг 2. Подготовь запуск

Скопируй `Install-RevitMcp.ps1` и `Install-RevitMcp.cmd` из папки `scripts` этого навыка в папку
набора. Если работаешь на этой же машине, можно не копировать, а передать путь:
`-KitDir "<папка набора>"`.

## Шаг 3. Пробный прогон

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-RevitMcp.ps1 -DryRun
```

Покажи человеку вывод: найденные версии Revit, результат сверки хэшей, команды установщиков,
строки регистрации и путь к файлу настроек Claude Desktop. Дождись согласия. Это единственное
подтверждение, которое нужно; не дроби его на несколько вопросов.

## Шаг 4. Установка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-RevitMcp.ps1
```

Человек может сделать то же сам двойным щелчком по `Install-RevitMcp.cmd`.

Что делает скрипт:

| Шаг | Действие |
| --- | --- |
| Проверки | Revit закрыт; найден Revit 2022–2027; установщики на месте; SHA-256 сверены со списком `Revit_MCP_Offline_SHA256SUMS.txt` из набора или со встроенной таблицей |
| Horizun | Тихая установка в профиль пользователя с ключами `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- /HORIZUNCLIENT=None`; успех определяется по файлу результата установщика, а не по коду возврата |
| BIMwright | Распаковка архива во временную папку и запуск его `install.ps1 -Client none`; затем проверка, что `rvt-mcp.exe --help` запускается |
| Claude Code | `claude mcp add --scope user` для обоих серверов; прежняя запись с тем же именем заменяется |
| Claude Desktop | Запись серверов в `claude_desktop_config.json` (сначала ищется установка из Магазина, затем обычная); перед изменением делается копия `*.bak-<дата>` |

Параметры запуска серверов:

- Horizun: `HORIZUN_PROFILE=completo`, `HORIZUN_SCHEMA_MODE=compact`.
- BIMwright: `--toolsets all --disable-send-code`.

Полезные ключи: `-Servers Horizun`, `-Clients ClaudeCode`, `-Clients None`,
`-BimwrightToolsets query,create`, `-HorizunProfile esencial`.

Права администратора не нужны. Если появился запрос контроля учётных записей — остановись и
сообщи человеку: штатная установка его не вызывает.

## Шаг 5. Проверка

Отчитывайся по трём пунктам раздельно и не объявляй готовность, пока не проверен каждый.

1. **Установка.** Скрипт завершился без `FAILED`. Существуют файлы
   `%LOCALAPPDATA%\Programs\Horizun\MCP\server\horizun-mcp.exe` и
   `%LOCALAPPDATA%\Bimwright\rvt-mcp\server\current\rvt-mcp.exe`.
2. **Клиент.** В Claude Code: `claude mcp list` показывает `horizun-revit` и `rvt-mcp`. Claude
   Desktop нужно полностью закрыть (значок в области уведомлений → «Выход») и открыть снова.
   Серверы появятся только в новом сеансе клиента: текущему сеансу их инструменты недоступны, и
   это не ошибка.
3. **Связь с Revit.** Попроси человека запустить Revit, на вопрос о надстройке ответить «Всегда
   загружать» и открыть копию проекта. В новом сеансе вызови инструмент состояния Horizun
   (найди его в списке инструментов, имя начинается с `horizun_`) и для BIMwright —
   `revit_get_current_view_info`. Если проверить из своего сеанса не можешь, так и скажи:
   «связь с Revit ожидает проверки человеком».

BIMwright запускается выключенным, если в этой версии Revit есть другая MCP-надстройка, то есть
рядом с Horizun — всегда. Включается кнопкой **Надстройки → RvtMcp → MCP: ON**. Скажи об этом
человеку заранее.

## Если что-то пошло не так

| Сообщение или признак | Что делать |
| --- | --- |
| `Revit is running` | Попросить человека закрыть Revit и повторить |
| `No Revit 2022-2027 found` | Revit не установлен; установка серверов без него бессмысленна |
| `SHA-256 mismatch` | Файл повреждён при передаче или это другая сборка. Попросить скачать его заново из набора. Не обходить |
| `no reference SHA-256` | В папке нет списка хэшей и версия не из встроенной таблицы. Попросить положить рядом `Revit_MCP_Offline_SHA256SUMS.txt` |
| `Horizun was not deployed for every Revit year` | Сервер стоит, но надстройка легла не во все версии Revit. Сообщить, какие годы не прошли; для них осталась прежняя установка |
| `Horizun setup left no result file` | Установщик не дошёл до конца (часто — открыт клиент, использующий прежнюю версию Horizun). Закрыть Claude и Revit, повторить |
| `BIMwright install.ps1 ended with exit code` | Прочитать вывод установщика выше по тексту; он сам откатывает изменения. Частая причина — найдены сразу старая и новая папки данных (`%LOCALAPPDATA%\RvtMcp` и `%LOCALAPPDATA%\Bimwright\rvt-mcp`): не сливать их самому, спросить человека |
| В клиенте нет инструментов | Клиент не перезапущен, либо запись сделана в другой файл настроек. Сверить путь из вывода скрипта |
| Инструменты есть, Revit не отвечает | Revit не запущен, нет открытого проекта, выбран ответ «Не загружать», либо BIMwright выключен кнопкой MCP |
| SmartScreen предупреждает о Horizun | Сборка 4.0.0 не подписана. Решение за человеком; хэш файла при этом уже сверен |

Повторный запуск скрипта безопасен: он обновляет установленное и заменяет свои записи в клиентах.

## Удаление

Скрипт ничего не удаляет. Horizun удаляется через «Приложения» Windows, BIMwright — его
`uninstall-all.ps1` из архива. Записи клиентов: `claude mcp remove --scope user horizun-revit`,
`claude mcp remove --scope user rvt-mcp`; для Claude Desktop — вернуть копию `*.bak-<дата>` или
убрать два раздела из `mcpServers`. Удаляй только по прямой просьбе человека.
