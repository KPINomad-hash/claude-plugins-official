# AEC Model Bridge — подключение к Claude Code

Плагин регистрирует в Claude Code MCP-сервер **AEC Model Bridge** (проверенная версия 1.4.0, лицензия GPL-3.0-or-later с исключением для связывания с Revit (либо коммерческая лицензия)).
Исходный проект: <https://github.com/Sam-AEC/aec-model-bridge>.

## Установка сервера

Запустите `AECModelBridge-Setup-1.4.0.exe`, проверьте, какие годы Revit выбрал мастер. Установка идёт в `C:\ProgramData\AECModelBridge` вместе со своим Python; для панели в Revit нужен WebView2.

Плагин ищет сервер по пути по умолчанию: `C:\ProgramData\AECModelBridge\python\python.exe`.
Если вы ставили в другое место, не используйте плагин, а зарегистрируйте сервер вручную: `claude mcp add <имя> -- "<полный путь>"`.

## Что важно знать

- Изменения модели выполняются только по плану, который человек подтверждает в панели Revit или утилитой `aec-model-bridge-approve`; через MCP подтвердить нельзя.
- Около 219 инструментов, включая `revit_execute_python` и вызовы API через рефлексию — они тоже проходят через подтверждение.
- Авторы прямо пишут, что ни одна версия Revit не проверена в живом сеансе (только компиляция в CI), а работа с Claude Code не тестировалась.
- Лицензия GPL — учитывайте при встраивании в собственные продукты.

## Перед использованием

- Плагин только подключает уже установленный сервер к Claude Code. Сам сервер и надстройку Revit нужно поставить на этой же машине Windows (см. выше).
- Откройте в Revit **копию** модели и начните с запроса состояния и списка инструментов.
- Это сторонний проект: Anthropic и автор этого репозитория его не проверяют и не сопровождают. Сравнение всех вариантов — в [`plugins/revit-mcp/docs/COMPARISON.md`](../../plugins/revit-mcp/docs/COMPARISON.md).
