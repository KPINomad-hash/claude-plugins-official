# BIMwright rvt-mcp — подключение к Claude Code

Плагин регистрирует в Claude Code MCP-сервер **BIMwright rvt-mcp** (проверенная версия 1.2.2, лицензия Apache-2.0).
Исходный проект: <https://github.com/bimwright/rvt-mcp>.

## Установка сервера

Распакуйте `RvtMcp.Setup-v1.2.2-win-x64.zip` и выполните `pwsh -File .\install.ps1 -Client none` — сервер и надстройки ставятся без правки настроек клиентов (подключение делает этот плагин).

Плагин ищет сервер по пути по умолчанию: `%LOCALAPPDATA%\Bimwright\rvt-mcp\server\current\rvt-mcp.exe`.
Если вы ставили в другое место, не используйте плагин, а зарегистрируйте сервер вручную: `claude mcp add <имя> -- "<полный путь>"`.

## Что важно знать

- Плагин запускает сервер с ключом `--disable-send-code`: инструмент `revit_send_code_to_revit` (компиляция и запуск произвольного C# внутри Revit) у этого сервера включён по умолчанию, здесь он отключён. Если он нужен, зарегистрируйте сервер вручную без этого ключа.
- Установщик записывает набор `all` (242 инструмента) — это большой расход контекста. Сократить можно ключом `--toolsets` или `--read-only` при ручной регистрации.
- Revit 2025+ — именованный канал с токеном; Revit 2022–2024 — локальный TCP-порт.

## Перед использованием

- Плагин только подключает уже установленный сервер к Claude Code. Сам сервер и надстройку Revit нужно поставить на этой же машине Windows (см. выше).
- Откройте в Revit **копию** модели и начните с запроса состояния и списка инструментов.
- Это сторонний проект: Anthropic и автор этого репозитория его не проверяют и не сопровождают. Сравнение всех вариантов — в [`plugins/revit-mcp/docs/COMPARISON.md`](../../plugins/revit-mcp/docs/COMPARISON.md).
