# BIMwright rvt-mcp — подключение к Claude Code

Плагин регистрирует в Claude Code MCP-сервер **BIMwright rvt-mcp** с полным каталогом инструментов.
Версия, по которой составлен плагин: 1.2.2 (Revit 2022–2027, лицензия Apache-2.0).
Исходный проект: <https://github.com/bimwright/rvt-mcp>.

Плагин не проверялся в работающем Revit: пути и ключи запуска взяты из документации и исходников проекта.

## Что умеет

Около 250 инструментов, из них более 50 создают элементы:

- **Конструкции:** несущие стены, балки, колонны, отдельные и ленточные фундаменты, наборы арматуры и хомуты.
- **Инженерные сети:** воздуховоды, трубы, кабельные лотки, короба, фитинги, воздухораспределители, светильники.
- **Архитектура и общее:** уровни, оси, помещения и пространства, зоны, элементы по точке, по линии и по поверхности, группы, загрузка семейств, дублирование типов.
- **Документация:** виды, выноски, листы, размещение видов и спецификаций на листах, спецификации, размеры, текст, фильтры и шаблоны видов, параметры проекта и общие параметры.

Остальное — запросы, проверки модели, редактирование и экспорт.

## Установка сервера

Распакуйте `RvtMcp.Setup-v1.2.2-win-x64.zip` из офлайн-набора и выполните при закрытом Revit:

```powershell
pwsh -File .\install.ps1 -Client none
```

Сервер и надстройки ставятся в профиль пользователя без правки настроек клиентов. Сервер самодостаточный: .NET, Node.js и Python ему не нужны.

Плагин ждёт сервер по пути `%LOCALAPPDATA%\Bimwright\rvt-mcp\server\current\rvt-mcp.exe`.

## Как плагин запускает сервер

```
rvt-mcp.exe --toolsets all --disable-send-code
```

- `--toolsets all` — весь каталог. Это большой расход контекста; если нужна только часть, зарегистрируйте сервер вручную с коротким списком, например `--toolsets query,create`.
- `--disable-send-code` — выключает `revit_send_code_to_revit`, то есть компиляцию и запуск произвольного C# внутри Revit. У самого сервера этот инструмент включён по умолчанию. Если он вам нужен, зарегистрируйте сервер вручную без этого ключа и подтверждайте каждый такой вызов.

## Claude Desktop

Плагины Claude Code на Claude Desktop не действуют. Добавьте сервер в `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "rvt-mcp": {
      "command": "C:\\Users\\<вы>\\AppData\\Local\\Bimwright\\rvt-mcp\\server\\current\\rvt-mcp.exe",
      "args": ["--toolsets", "all", "--disable-send-code"]
    }
  }
}
```

Либо поставьте сервер командой `install.ps1 -Client claude-desktop` — тогда установщик сам запишет настройку, но без `--disable-send-code`.

## Что важно знать

- Revit 2025 и новее: связь по именованному каналу с токеном. Revit 2022–2024: локальный TCP-порт.
- Не разрешайте в Claude Code все инструменты разом шаблоном `mcp__rvt-mcp__*`: изменяющие вызовы лучше подтверждать.
- Первый запуск делайте на копии модели.
- Это сторонний проект; Anthropic его не проверяет и не сопровождает.
- Не включайте этот сервер одновременно с Horizun в одной сессии без необходимости: инструменты двух серверов пересекаются по смыслу и занимают контекст.
