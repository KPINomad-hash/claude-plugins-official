# s81 Autodesk MCP — подключение к Claude Code

Плагин регистрирует в Claude Code MCP-сервер **s81 Autodesk MCP** (проверенная версия 0.3.1, лицензия MIT).
Исходный проект: <https://github.com/s81/Autodesk--mcp>.

## Установка сервера

Распакуйте `AutodeskMcp-All-v0.3.1.zip` и выполните, например, `powershell -File scripts\install.ps1 -RevitYears 2026 -SkipAutoCAD`. Права администратора не нужны, сервер самодостаточный.

Плагин ищет сервер по пути по умолчанию: `%LOCALAPPDATA%\AutodeskMcp\server\AutodeskMcp.Server.exe`.
Если вы ставили в другое место, не используйте плагин, а зарегистрируйте сервер вручную: `claude mcp add <имя> -- "<полный путь>"`.

## Что важно знать

- 24 инструмента (12 для Revit, 11 для AutoCAD). Связь — именованный канал текущего пользователя и токен.
- **Изменения и выполнение произвольного C# (`revit_execute_csharp`) включены по умолчанию.** Чтобы отключить, задайте в `%LOCALAPPDATA%\AutodeskMcp\config.json` значения `"allowCodeExecution": false` и при необходимости `"allowModifications": false`.
- Телеметрии, проверок обновлений и сетевых обращений в исходниках не найдено.

## Перед использованием

- Плагин только подключает уже установленный сервер к Claude Code. Сам сервер и надстройку Revit нужно поставить на этой же машине Windows (см. выше).
- Откройте в Revit **копию** модели и начните с запроса состояния и списка инструментов.
- Это сторонний проект: Anthropic и автор этого репозитория его не проверяют и не сопровождают. Сравнение всех вариантов — в [`plugins/revit-mcp/docs/COMPARISON.md`](../../plugins/revit-mcp/docs/COMPARISON.md).
