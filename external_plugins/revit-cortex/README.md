# RevitCortex — подключение к Claude Code

Плагин регистрирует в Claude Code MCP-сервер **RevitCortex** (проверенная версия 1.0.25, лицензия MIT).
Исходный проект: <https://github.com/LuDattilo/RevitCortex>.

## Установка сервера

Сначала поставьте **Git for Windows** из набора и проверьте `git --version` в новом окне PowerShell (иначе установщик попытается скачать Git из интернета). Затем распакуйте `RevitCortex-v1.0.25.zip` и запустите `install.ps1`.

Плагин ищет сервер по пути по умолчанию: `%USERPROFILE%\.revitcortex\server\RevitCortex.Server.exe`.
Если вы ставили в другое место, не используйте плагин, а зарегистрируйте сервер вручную: `claude mcp add <имя> -- "<полный путь>"`.

## Что важно знать

- Связь с Revit — TCP `127.0.0.1:8080` **без токена**: к надстройке может подключиться любой локальный процесс. Порт меняется переменной `REVITCORTEX_PORT`.
- Установщик запрашивает повышение прав, предлагает добавить исключение в Защитник Windows (можно отказаться) и сам правит `claude_desktop_config.json`.
- При каждом запуске надстройка проверяет обновления на `raw.githubusercontent.com`; на офлайн-станции запрос просто не пройдёт. Телеметрия выключена до явного согласия.
- Выполнение произвольного кода (`send_code_to_revit`) по умолчанию выключено.
- В коде есть заготовка лицензирования (ключи, привязка к машине), сейчас не действующая; исходники выпускаемых сборок, по комментарию в коде, ведутся в закрытом репозитории.

## Перед использованием

- Плагин только подключает уже установленный сервер к Claude Code. Сам сервер и надстройку Revit нужно поставить на этой же машине Windows (см. выше).
- Откройте в Revit **копию** модели и начните с запроса состояния и списка инструментов.
- Это сторонний проект: Anthropic и автор этого репозитория его не проверяют и не сопровождают. Сравнение всех вариантов — в [`plugins/revit-mcp/docs/COMPARISON.md`](../../plugins/revit-mcp/docs/COMPARISON.md).
