# KenLP RevitMCPServer — подключение к Claude Code

Плагин регистрирует в Claude Code MCP-сервер **KenLP RevitMCPServer** (проверенная версия 0.8.43, лицензия MIT).
Исходный проект: <https://github.com/KenLP/RevitMCPServer>.

## Установка сервера

Поставьте Node.js 24 из набора и следуйте разделу «KenLP без доступа к npm» инструкции: `install.ps1 -SkipNpm -NoClientConfig`, затем `npm.cmd ci --offline …` из кэша.

Плагин ищет сервер по пути по умолчанию: `%LOCALAPPDATA%\RevitMCPServer\dist\index.js`.
Если вы ставили в другое место, не используйте плагин, а зарегистрируйте сервер вручную: `claude mcp add <имя> -- "<полный путь>"`.

## Что важно знать

- **Версия Revit задаётся переменной окружения `REVIT_MCP_VERSION`** (2025, 2026 или 2027; по умолчанию 2026). От неё зависит локальный порт надстройки: 7890, 7891, 7892.
- `REVIT_MCP_PROFILE` — необязательный список групп инструментов через запятую (`inspection`, `model-health`, `editing`, `view` и др.); пусто — все ~100 инструментов.
- Связь — HTTP только на `127.0.0.1` с токеном, который создаётся заново при каждом запуске Revit.
- Произвольного выполнения кода нет. Есть предварительный просмотр изменений (dry-run) и журнал изменений.

## Перед использованием

- Плагин только подключает уже установленный сервер к Claude Code. Сам сервер и надстройку Revit нужно поставить на этой же машине Windows (см. выше).
- Откройте в Revit **копию** модели и начните с запроса состояния и списка инструментов.
- Это сторонний проект: Anthropic и автор этого репозитория его не проверяют и не сопровождают. Сравнение всех вариантов — в [`plugins/revit-mcp/docs/COMPARISON.md`](../../plugins/revit-mcp/docs/COMPARISON.md).
