# Horizun Revit MCP — подключение к Claude Code

Плагин регистрирует в Claude Code MCP-сервер **Horizun Revit MCP** (проверенная версия 4.0.0, лицензия Apache-2.0).
Исходный проект: <https://github.com/HorizunGroup/horizun-revit-mcp>.

## Установка сервера

Закройте Revit и запустите `horizun-mcp-4.0.0-setup.exe` из офлайн-набора. Установка идёт в профиль пользователя, права администратора не нужны, среда выполнения входит в установщик.

Плагин ищет сервер по пути по умолчанию: `%LOCALAPPDATA%\Programs\Horizun\MCP\server\horizun-mcp.exe`.
Если вы ставили в другое место, не используйте плагин, а зарегистрируйте сервер вручную: `claude mcp add <имя> -- "<полный путь>"`.

## Что важно знать

- Связь с Revit — именованный канал текущего пользователя и токен; сетевые порты не открываются.
- По умолчанию включён профиль из 14 инструментов; остальные доступны через `horizun_list_tools` и `horizun_activate_toolset`.
- Выполнение произвольного Python (`horizun_execute_python`) выключено, пока владелец не включит его кнопкой на ленте Revit.
- Сборка 4.0.0, по данным репозитория, не подписана сертификатом (подпись заявлена с 4.0.1) — Windows SmartScreen может предупредить.

## Перед использованием

- Плагин только подключает уже установленный сервер к Claude Code. Сам сервер и надстройку Revit нужно поставить на этой же машине Windows (см. выше).
- Откройте в Revit **копию** модели и начните с запроса состояния и списка инструментов.
- Это сторонний проект: Anthropic и автор этого репозитория его не проверяют и не сопровождают. Сравнение всех вариантов — в [`plugins/revit-mcp/docs/COMPARISON.md`](../../plugins/revit-mcp/docs/COMPARISON.md).
