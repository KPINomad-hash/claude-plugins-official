# Horizun Revit MCP — подключение к Claude Code

Плагин регистрирует в Claude Code MCP-сервер **Horizun Revit MCP** с полным профилем инструментов.
Версия, по которой составлен плагин: 4.0.0 (Revit 2023–2027, лицензия Apache-2.0).
Исходный проект: <https://github.com/HorizunGroup/horizun-revit-mcp>.

Плагин не проверялся в работающем Revit: пути и переменные запуска взяты из документации и исходников проекта.

## Что умеет

В полном профиле 113 инструментов. Моделирование построено не на отдельном инструменте для каждого типа элемента, а на планах:

- **Планы построения:** конструкции (`horizun_plan_structure`), армирование (`horizun_plan_reinforcement`), инженерные сети (`horizun_plan_mep`, `horizun_mep_routing`), виды и аннотации.
- **Из чертежей и обменных форматов:** построение по DWG (`horizun_plan_from_cad`, распознавание сетей и условных обозначений) и по IFC (`horizun_plan_from_ifc`).
- **Создание:** общий `horizun_create_elements`, семейства (`horizun_create_family`), ограждения, спецификации, узлы металлоконструкций.
- **Исполнение:** `horizun_execute_plan` выполняет до 100 действий одной группой транзакций с откатом целиком.

Запись идёт в три шага: репетиция, выдача токена, применение с повторным чтением результата.

## Установка сервера

Закройте Revit и запустите `horizun-mcp-4.0.0-setup.exe` из офлайн-набора. Установка идёт в профиль пользователя, права администратора не нужны, среда выполнения входит в установщик.

Плагин ждёт сервер по пути `%LOCALAPPDATA%\Programs\Horizun\MCP\server\horizun-mcp.exe`.

## Как плагин запускает сервер

С переменными окружения:

- `HORIZUN_PROFILE=completo` — полный профиль вместо стандартного `esencial` (14 инструментов).
- `HORIZUN_SCHEMA_MODE=compact` — сокращённые описания инструментов, чтобы полный профиль занимал меньше контекста.

## Claude Desktop

Плагины Claude Code на Claude Desktop не действуют. Добавьте сервер в `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "horizun-revit": {
      "command": "C:\\Users\\<вы>\\AppData\\Local\\Programs\\Horizun\\MCP\\server\\horizun-mcp.exe",
      "env": { "HORIZUN_PROFILE": "completo", "HORIZUN_SCHEMA_MODE": "compact" }
    }
  }
}
```

Либо установите `horizun-revit-4.0.0.mcpb` из набора; тогда профиль задаётся настройками самого сервера.

## Что важно знать

- Связь с Revit — именованный канал текущего пользователя и токен; сетевые порты не открываются.
- Выполнение произвольного Python (`horizun_execute_python`) выключено, пока вы сами не включите его кнопкой на ленте Revit.
- Сборка 4.0.0, судя по репозиторию, не подписана сертификатом (подпись заявлена с 4.0.1): Windows SmartScreen может показать предупреждение.
- Облачные функции (APS, Power BI, Application Insights) выключены, пока им не заданы учётные данные.
- Первый запуск делайте на копии модели.
- Это сторонний проект; Anthropic его не проверяет и не сопровождает.
- Не включайте этот сервер одновременно с BIMwright в одной сессии без необходимости: инструменты двух серверов пересекаются по смыслу и занимают контекст.
